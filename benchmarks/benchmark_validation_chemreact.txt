Expected discrepancy scenarios:
1. Auto coding from observed min/max
- Same fitted values and same R2.
- Different coefficients because the scale changes from half-range 5 to half-range 7.07.
- This is not a model error; it is a coding-definition difference.

2. Omitting the block term
- R2 collapses to about 0.282593.
- The intercept and variance partitioning become wrong because block-to-block shift is absorbed into residuals.
- This is a true model-specification error.
